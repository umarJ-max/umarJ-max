## NAME

**umar** — self-taught developer; ships things, occasionally reads the docs first

## SYNOPSIS

```
umar [--coffee] [--sleep=false] [--idea "3am"] [--ship now]
```

## DESCRIPTION

**umar** is a lightweight process that turns spare time into working software.
Written entirely in trial-and-error, with no formal compiler (i.e. no CS degree).
Known to spawn child processes with names like `doc-tools`, `jarvis`, `rootchat`,
and at least four WhatsApp bots that refuse to stay dead.

Behavior is deterministic in one way only: if it can be automated, it will be —
whether or not that was the efficient choice.

## OPTIONS

```
  -v, --verbose        talks through the architecture before you asked
  -f, --fast           ships first, writes docs never
  -d, --debug          6 hours in, turns out it was a typo
  --free-tier          deploys exclusively on free hosting until it dies
  --then-what          rebuilds it somewhere else and keeps going
```
